# TypeScript の戻り値の型

- `src/server/routes/` 配下は、このルールの対象外とする。Hono RPC に必要なルート・レスポンスの型推論を維持するため、ルート生成関数やハンドラーの戻り値の型注釈は省略してよい。
- 関数宣言、メソッド、変数に代入する関数式・アロー関数には、戻り値の型を明記する。export の有無を問わない。
- 値を返さない関数には `void`、非同期関数には `Promise<T>` を指定する。
- `null`・`undefined` を返す場合は、それらを含む union 型を明記する。
- 呼び出し先から型が決まるインラインのコールバック（例: `map` やイベントハンドラー）は、戻り値の型注釈を省略してよい。
- 変数自体に関数型を指定している場合は、関数側に戻り値の型注釈を重複して書く必要はない。
- 既存の関数を編集する際も、戻り値の型が省略されていれば追加する。
